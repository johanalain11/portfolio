# Portfolio de Johan Alain NZALI KENGMEGNIE

Portfolio personnel développé avec Next.js pour présenter mes compétences, mes projets, mon expérience et mes coordonnées.

## Présentation

Ce site sert de vitrine professionnelle et numérique. Il met en avant :

- une section d'introduction / hero
- une présentation personnelle
- les compétences techniques
- l'expérience professionnelle
- les projets réalisés
- un formulaire de contact
- une navigation moderne et responsive
- une version multilingue (français / anglais)

## Stack technique

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Motion / animations UI
- Vercel Analytics
- Tests via Vitest

## Fonctionnalités

- Design moderne et immersif
- Interface responsive pour mobile, tablette et desktop
- Navigation avec sections ancrées
- Compatible multilingue
- Thème sombre / clair selon le contexte
- Structure orientée contenus pour faciliter la mise à jour

## Prérequis

Avant de lancer le projet, vérifiez que vous avez installé :

- Node.js 20+
- npm

## Installation

```bash
npm install
```

## Démarrage

Lancer le serveur de développement :

```bash
npm run dev
```

Puis ouvrir :

```text
http://localhost:3000
```

## Scripts disponibles

```bash
npm run dev      # démarre l'application en mode développement
npm run build    # construit l'application pour la production
npm run start    # démarre la build de production
npm run lint     # vérifie le code avec ESLint
npm run test     # exécute les tests Vitest
npm run typecheck # vérifie les types TypeScript
npm run format   # formate le projet avec Prettier
```

## Structure du projet

```text
.
├── app/                # routes Next.js et pages
├── components/         # composants réutilisables UI
├── data/               # contenus statiques (profil, projets, compétences, expérience)
├── features/           # sections de la landing page
├── lib/                # helpers et utilitaires
├── public/             # fichiers statiques
├── messages/           # fichiers de traduction
├── tests/              # tests
├── types/              # types TypeScript
├── package.json        # dépendances et scripts
├── next.config.ts      # configuration Next.js
├── i18n.config.ts      # configuration i18n
├── README.md           # documentation du projet
└── ...
```

## Déploiement

Le projet est prêt pour un déploiement sur Vercel ou tout autre hébergeur compatible Next.js.

Pour déployer sur Vercel :

1. connecter le dépôt GitHub
2. importer le projet dans Vercel
3. configurer la build si nécessaire
4. publier
